## Исправления версии 0.0.4

- Промежуточные Python-списки заменены локальными C-массивами ограниченного размера.
  Устранены утечки ссылок, неверные удаления элементов и изменение уже возвращаемых решений.
- Исправлен запасной поиск: лишняя точка с запятой, неверная область цикла,
  обработка крайних индексов, включая `k == 0`.
- Каждое решение возвращается отдельным списком из шести чисел.
- Проверяются количество аргументов, размеры массивов, конечность чисел,
  порядок лимитов, положительные длины бедра/голени и ненулевое направление стопы.
- Обрабатываются ошибки выделения Python-объектов, не выдаются решения с NaN/Inf.
- Убран двойной вызов `setup()`.

Геометрия, формулы, порядок ветвей, коэффициенты преобразования и соглашения
об углах сохранены. Это исправление реализации, а не новый метод IK.
Остаются особенности исходного алгоритма: эвристический поиск по сетке,
отсутствие проверки остатка найденного корня, исходная коррекция ветвей,
неиспользуемые `c5` и лимит `alpha5`. Поэтому непустой результат сам по себе
не является доказательством геометрической точности или безопасности движения.

## API

```python
import starkit
solutions = starkit.alpha_calculation(xt, yt, zt, x, y, z, w, sizes, limits)
```

Положение стопы задаётся в миллиметрах; `(x, y, z)` задаёт направление, `w` в радианах.
`sizes`: `[a5, b5, c5, a6, a7, a8, a9, a10, b10, c10]`.
`limits`: шесть пар границ для `alpha5..alpha10` в исходных единицах Kondo.
Результат: список решений `[alpha10, alpha9, alpha8, alpha7, alpha6, alpha5]`, в радианах.
Отсутствие решения: `[]`. Некорректные аргументы: `TypeError` или `ValueError`.
Это расчёт желаемых углов, без чтения фактических позиций сервоприводов.

## Сборка и проверки

Нужны C-компилятор, заголовки Python и setuptools. Eigen и pybind11 не требуются.

```sh
python setup.py build_ext --inplace
python -m unittest discover -s tests -v
python tools/replay_gait.py --roki-ng ../roki-ng --module-dir . --output /tmp/starkit-replay
```

Последняя команда запускает настоящий генератор походки из `roki-ng`, но не
импортирует библиотеку Roki, не открывает порты и не отправляет команды роботу.
Она записывает входы IK, решения и выдаваемые команды серв в `trace.jsonl`;
итоги находятся в `summary.json`. Проверяются ходьба на месте, вперёд/назад,
вбок, повороты, комбинированная ходьба, шаг 64 мм; обе ведущие ноги и подъём 32/40 мм.
Проверка диапазона команды 0..16383 не заменяет проверку механических лимитов.

Результаты сравнения с исходной версией: [TEST_RESULTS.md](TEST_RESULTS.md).
